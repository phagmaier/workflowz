# Superseded UI prototypes

These [design directions](design-directions/index.html) were retired on 2026-10-21. They use
sample data and do not run the daemon or call providers. Their relative assets are preserved.

They predate the approved dark Workbench design. In particular, their direction C is named
**Studio**, not the selected **Workbench**. Do not implement these as the current design.
The approved canvas and current requirements are linked from [DESIGN.md](../../DESIGN.md#decisions).
